# Known Issues

Keywords: bug, issue, workaround, limitation, technical-debt, risk

- **KI-001: Kimchi workflows are placeholders**
  - The `.github/workflows/kimchi-*.yml` files exit with `exit 0` until the real Kimchi runner is wired.
  - Impact: autonomous agent cycles are scheduled but do not execute real work yet.
  - Workaround: manually trigger agent cycles or replace placeholder commands with the real Kimchi CLI invocation.
- **KI-002: Deploy scripts not defined**
  - `.kimchi/AUTONOMY.md` previously referenced `npm run deploy:staging` and `npm run deploy:production`, which do not exist in `package.json`.
  - Impact: autonomous deploy will fail if enabled.
  - Workaround: staging deploy is disabled in `AUTONOMY.md`; enable only after adding real deploy scripts.
- **KI-003: Generated agent metadata should stay ignored**
  - `.claude/ecc-tools.json`, `.claude/identity.json`, `.claude/homunculus/`, `.codex/`, `.agents/` are generated by external tooling and should not be committed.
  - Impact: accidentally committing these creates churn and potential security/confusion issues.
  - Workaround: `.gitignore` now ignores them; `git ls-files` should show none tracked.
